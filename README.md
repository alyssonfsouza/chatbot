# 💬 ChatBot - Seu Assistente Java

Bem-vindo ao **ChatBot**, um projeto de assistente virtual interativo desenvolvido em **Java**. Atualmente em desenvolvimento, este chatbot já oferece respostas para suas dúvidas sobre **Projeto de Software**, **Inteligência Artificial (IA)**, **Linguagem Java** e até mesmo permite o **cálculo de média simples**.

O objetivo é ser uma ferramenta útil e direta para quem busca informações rápidas sobre esses tópicos!

---

## 🚀 Como Rodar o Projeto

Para executar o ChatBot em sua máquina, siga estes passos simples:

### Pré-requisitos

* **Java Development Kit (JDK)**: Versão 8 ou superior. Baixe em [oracle.com/java](https://www.oracle.com/java/technologies/downloads/).

### Passos

1.  **Clone o Repositório:**
    ```bash
    git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
    cd seu-repositorio
    ```
    *(Ajuste `seu-usuario` e `seu-repositorio` para os dados do seu projeto).*

2.  **Compile o Código:**
    No terminal, na pasta raiz do projeto:
    ```bash
    javac App.java
    ```

3.  **Execute o ChatBot:**
    ```bash
    java App
    ```
    Agora é só interagir com o chatbot no seu terminal!

---

## 💡 Como Usar

Ao iniciar, o ChatBot irá guiá-lo. Use os seguintes comandos-chave:

* Responda "**sim**" ou "**nao**" à saudação inicial.
* Para tópicos, digite uma das opções: "**Projeto**", "**IA**", "**Java**" ou "**Media**".
* Dentro de um tópico, selecione uma opção (ex: "**1**", "**2**") ou digite "**voltar**" para retornar.
* Para finalizar a conversa a qualquer momento, digite "**sair**".
